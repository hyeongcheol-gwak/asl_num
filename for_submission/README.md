# ASL 손동작 인식 과제 제출 패키지

이 패키지는 MLP 모델을 사용하여 영상에서 ASL(미국 수화) 손동작을 인식하는 시스템입니다.

## 📁 파일 구성

- `1_collect_data.py` - 데이터 수집 스크립트
- `2_create_video.py` - 테스트 영상 생성 스크립트
- `3_evaluate_video.py` - 영상 평가 및 인식 스크립트
- `README.md` - 사용 설명서 (이 파일)

## 🔧 필요한 라이브러리

```bash
pip install opencv-python mediapipe numpy torch
```

## 📝 사용 방법

### 1단계: 데이터 수집

웹캠을 사용하여 손동작 데이터를 수집합니다.

```bash
cd for_submission
python 1_collect_data.py
```

**조작 방법:**
- **Space 키**: 현재 프레임 캡처
- **0-9 키**: 캡처된 이미지에 라벨(0~9) 지정 및 저장
- **ESC 키**: 종료

**수집 가이드:**
- 각 숫자(0-9)마다 여러 번 촬영하는 것을 권장합니다
- 다양한 배경에서 촬영하면 더 좋은 테스트가 가능합니다
- 같은 숫자를 다른 조건(위치, 배경, 조명)에서 촬영하세요
- 최소 10개 이상의 샘플을 수집하는 것을 권장합니다

**출력:**
- `collected_data/` 폴더에 이미지 파일(.jpg)과 메타데이터(.json) 저장

---

### 2단계: 테스트 영상 생성

수집한 데이터로 테스트 영상을 만듭니다.

```bash
python 2_create_video.py
```

**동작:**
- `collected_data/` 폴더의 모든 샘플을 순서대로 영상에 포함
- 각 샘플은 15프레임씩 반복되어 영상에 추가됩니다
- 30 FPS로 영상 생성

**출력:**
- `test_video.mp4` - 테스트 영상
- `ground_truth.txt` - 정답 파일 (각 줄에 하나의 숫자)

---

### 3단계: 영상 평가

MLP 모델을 사용하여 생성된 영상을 평가합니다.

```bash
python 3_evaluate_video.py
```

**동작:**
- `../train/mlp.pth` 모델 로드
- `test_video.mp4` 영상을 프레임별로 처리
- MediaPipe로 손 랜드마크 추출
- MLP 모델로 손동작 분류
- **제스처 전환 감지**: 
  - 다른 라벨이 안정적으로 나타날 때
  - 같은 라벨이지만 랜드마크 변화가 큰 경우 (배경/손 변화)

**출력:**
- `prediction.txt` - 예측 결과 (각 줄에 하나의 숫자)
- 콘솔에 정확도 출력

**제스처 구분 로직:**
```
1. 안정성 체크: 10프레임 중 80% 이상 동일한 예측
2. 새 제스처 감지:
   - 이전 제스처와 다른 라벨인 경우
   - 같은 라벨이지만 랜드마크 변화량 > 0.15 (배경/손 변경)
```

## 🎯 전체 워크플로우 예시

```bash
# 1. 데이터 수집 (약 10-20개 샘플)
python 1_collect_data.py

# 2. 영상 생성
python 2_create_video.py

# 3. 영상 평가
python 3_evaluate_video.py
```

## 📊 결과 해석

### 정확도 평가
- `ground_truth.txt`와 `prediction.txt`를 비교
- 각 제스처별로 정답과 예측을 매칭
- 전체 정확도(%) 계산

### 예시 출력
```
정답 (Ground Truth): [1, 2, 2, 3, 1]
예측 (Prediction):   [1, 2, 2, 3, 1]

정확도: 5/5 = 100.00%

상세 비교:
  1. 정답: 1, 예측: 1 ✓
  2. 정답: 2, 예측: 2 ✓
  3. 정답: 2, 예측: 2 ✓
  4. 정답: 3, 예측: 3 ✓
  5. 정답: 1, 예측: 1 ✓
```

## ⚙️ 설정 변경

각 스크립트의 상단에 있는 설정 변수를 수정할 수 있습니다:

### `2_create_video.py`
```python
FRAMES_PER_IMAGE = 15  # 각 이미지당 프레임 수
FPS = 30              # 초당 프레임 수
```

### `3_evaluate_video.py`
```python
STABILITY_FRAMES = 10      # 안정성 판단 프레임 수
CHANGE_THRESHOLD = 0.15    # 랜드마크 변화 임계값
```

## 🔍 문제 해결

### 문제: 손이 감지되지 않음
- 조명을 밝게 하세요
- 배경과 손의 대비를 높이세요
- 카메라와의 거리를 조절하세요

### 문제: 같은 제스처가 여러 번 인식됨
- `CHANGE_THRESHOLD` 값을 낮춰보세요 (더 민감하게)
- 데이터 수집 시 배경을 더 다양하게 하세요

### 문제: 다른 제스처가 하나로 인식됨
- `CHANGE_THRESHOLD` 값을 높여보세요 (덜 민감하게)
- `STABILITY_FRAMES` 값을 조절하세요
